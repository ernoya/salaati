# 🕌 مواقيت الصلاة والأذان — Prayer Now Clone (Flutter)

نسخة كاملة الوظائف من تطبيق **Prayer Now: Azan Prayer Times** مكتوبة بـ Flutter،
تعمل على **Android / iOS / Web**، ويغلب عملها **بدون إنترنت**.

> ⚠️ ملاحظة قانونية: هذا مشروع برمجي مستقل يحاكي **الوظائف** ولا يستخدم اسم أو شعار
> أو أصول التطبيق الأصلي (App Rocks). قبل النشر على المتاجر: عدّل اسم الحزمة
> (`com.prayernow.app`) والاسم الظاهر والشعار، وراجع حقوق ملفات الصوت.

## 🚀 التشغيل

```bash
# 1) متطلبات: Flutter 3.24+ و Dart 3.5+
flutter --version

# 2) تنصيب الحزم
flutter pub get

# 3) تشغيل
flutter run                 # على جهاز/محاكي متصل
flutter run -d chrome       # نسخة الويب
```

### بناء APK

```bash
flutter build apk --release --split-per-abi
# الناتج: build/app/outputs/flutter-apk/app-arm64-v8a-release.apk
```

> الإشعارات الصوتية على أندرويد تحتاج ملفات الصوت في `android/app/src/main/res/raw/`
> (موجودة بالفعل: athan_makkah.mp3, athan_madina.mp3, athan_alafasy.mp3, notification.wav).

### نسخة الويب (PWA)

```bash
flutter build web --release
# ثم انشر محتوى build/web على أي استضافة ساكنة
```
التطبيق يُثبَّت على الشاشة الرئيسية كتطبيق مستقل (`manifest.json` + أيقونات جاهزة).

### iOS

```bash
cd ios && pod install && cd ..
flutter build ios --release
```
صلاحيات الموقع مضبوطة في `ios/Runner/Info.plist`.

## 🔧 ما ينقص للإنتاج (خطوات اختيارية)

1. **أذان المتصفح على الويب**: محدوديات المتصفح تمنع التشغيل التلقائي للصوت — الأذان يبدأ بضغطة أو يظهر كإشعار.
2. **Audio Focus / إيقاف الإشعارات أثناء المكالمات**: تحتاج قناة أندرويد أصلية (MethodChannel).
3. **تلاوات القرآن الصوتية**: النص كامل محليًا؛ الصوت يمكن ربطه بـ API تلاوات عند الطلب.
4. **Wear OS Tiles / Widgets** كما في الأصل: تحتاج وحدة Kotlin منفصلة.
